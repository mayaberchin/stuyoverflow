## Our Project
Stuy Overflow is a StuyCS tailored discussion platform inspired by Piazza (and Stack Overflow).
It provides a centralized space for communication, academic support, and easier access to resources within the StuyCS community.
Users will be able to create and repond to questions and share resources; teachers will be able to create assignments and announcements as well as respond to student questions.

## Install Guide:

#### 1) Clone Repository
Open your terminal and navigate to the directory/folder you want to copy our app into.  
Run the following command:
```
git clone git@github.com:procrastinAFK/brune.git
```
Navitage into the directory: 
```
cd brune
```

##### 2) Virtual Environment
To create the virtual environment, run it, and install the requirements for our app, run the following commands:
```
python3 -m .venv venv
. .venv/bin/activate
pip install -r requirements.txt
```


## Launch Codes

#### Run the app:
Navigate into the app by running the following command:
```
cd app
```
Now you can run the app:
```
python3 __init__.py
```
